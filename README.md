
# 📚 ETEC - Desenvolvimento de Sistemas (DS-AMS)

Bem-vindo à pasta **DS-AMS**, que contém materiais, exercícios e projetos do curso de **Desenvolvimento de Sistemas** da **ETEC**. O conteúdo está organizado por **ano e matéria**, facilitando o acesso rápido ao que você precisa estudar ou revisar.
